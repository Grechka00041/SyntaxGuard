# SyntaxGuard

**SyntaxGuard** — учебный анализатор пунктуации русского языка. Программа использует морфологический анализ `pymorphy3`, набор эвристических правил для поиска распространённых пунктуационных ошибок и учебную контекстно-свободную грамматику (CFG) для построения синтаксических деревьев.

Проект демонстрирует два связанных, но независимых процесса:

- **пунктуационный анализ** — поиск возможных пропущенных запятых и формирование рекомендаций;
- **синтаксический анализ** — построение возможной структуры предложения по последовательности морфологических категорий.

Отсутствие синтаксического дерева не означает, что предложение грамматически или пунктуационно неверно.

## Основные возможности

### Проверка пунктуации

В проекте реализованы девять групп эвристических проверок:

1. Причастные обороты.
2. Деепричастные обороты.
3. Вводные слова и конструкции.
4. Однородные члены предложения.
5. Обращения.
6. Сложносочинённые предложения.
7. Сравнительные обороты.
8. Уточняющие члены предложения.
9. Противительные союзы.

Для найденного замечания интерфейс показывает название правила, объяснение, предполагаемое место запятой и рекомендацию. Вводимый текст разделяется на предложения, после чего каждое предложение анализируется отдельно.

### Морфологический анализ

Модуль `preprocessor.py` выполняет токенизацию и морфологический анализ с помощью `pymorphy3`. Для слов определяются леммы, части речи и морфологические характеристики, необходимые пунктуационным эвристикам и синтаксическому парсеру.

### Контекстно-свободная грамматика и синтаксический анализ

В `syntax_parser.py` реализована учебная контекстно-свободная грамматика на базе `nltk.CFG`. Для синтаксического разбора используется `nltk.ChartParser`.

Последовательность работы:

1. Препроцессор получает токены предложения и их морфологические характеристики.
2. `SyntaxParser` преобразует морфологические категории в терминалы грамматики. В частности, для CFG различаются глагол и инфинитив, полные и краткие причастия, имена собственные и другие категории.
3. `ChartParser` сопоставляет последовательность терминалов с продукциями CFG.
4. При успешном разборе формируется дерево NLTK. Листья дерева содержат исходные слова, внутренние узлы — синтаксические категории.
5. Парсер может вернуть несколько вариантов разбора; по умолчанию выводится не более трёх деревьев.

В грамматике используются, в частности, следующие нетерминалы:

| Обозначение | Значение |
|---|---|
| `S` | Предложение целиком |
| `CLAUSE` | Предикативная часть |
| `NP` | Именная группа |
| `VP` | Глагольная группа |
| `PP` | Предложная группа |
| `ADDR` | Обращение |
| `HOMOG_NP` | Однородная именная группа |
| `GREETING_PHRASE` | Устойчивая формула приветствия |

Грамматика CFG v2 расширена правилами для распространённых учебных конструкций:

- простые предложения с именной и глагольной группами;
- предложения с двумя или тремя предикативными частями, соединёнными союзом;
- обращения в типовых побудительных конструкциях;
- приветствия: «Дима, привет», «Привет, Дима», «Доброе утро, Дима»;
- конструкции «глагол + инфинитив»: «Пошли гулять?»;
- типовые однородные группы существительных и прилагательных;
- именные группы с прилагательными и причастиями;
- предложные группы и отдельные обстоятельственные конструкции.

Запятые исключаются из входной последовательности CFG: грамматика анализирует синтаксическую структуру, а пунктуационные модули проверяют знаки препинания независимо. Поэтому синтаксическое дерево не является само по себе подтверждением правильной пунктуации.

Грамматика ограничена набором учебных правил и не предназначена для полного синтаксического разбора любых русских предложений. Если разбор не найден, интерфейс сообщает об этом отдельно и не трактует отсутствие дерева как пунктуационную ошибку.

Подробное описание продукций, этапов разбора и примеров находится в [`docs/CFG_AND_PARSING.md`](docs/CFG_AND_PARSING.md).

### Графическое отображение синтаксических деревьев

Модуль `tree_visualizer.py` преобразует структурированное представление дерева в SVG-схему. Визуализация отображается непосредственно в интерфейсе Streamlit.

- Синтаксические группы показаны отдельными узлами.
- Листья дерева содержат часть речи и исходное слово.
- Соединительные линии показывают иерархию дерева.
- Рядом с формальными обозначениями выводятся русские пояснения: например, `NP` — «Именная группа», `VP` — «Глагольная группа», `NOUN` — «Существительное».
- Доступны графическое и текстовое представления дерева, а также раскрывающаяся справка по обозначениям.

Для SVG-визуализации не требуется устанавливать Graphviz или дополнительные системные программы. Пример дерева сохранён в `docs/examples/syntax_tree_student_ru.png`.

## Как устроен проект

```text
SyntaxGuard/
├── app.py                 # Веб-интерфейс Streamlit
├── analyzer.py            # Координация пунктуационных правил и CFG-разбора
├── preprocessor.py        # Токенизация и морфологический анализ
├── syntax_parser.py       # CFG-грамматика и ChartParser
├── tree_visualizer.py     # SVG-визуализация синтаксических деревьев
├── ui_helpers.py          # Вспомогательные функции интерфейса
├── evaluate.py            # Запуск оценки тестового корпуса
├── evaluation.py          # Расчёт метрик качества
├── requirements.txt       # Зависимости проекта
├── rules/                 # Девять групп пунктуационных проверок
├── tests/                 # Модульные и интеграционные тесты
├── data/                  # Размеченные тестовые корпуса
├── reports/               # Сохранённые отчёты оценки
└── docs/                  # Документация и примеры
```

### Основные технологии

- **Python** — язык реализации.
- **pymorphy3** — морфологический анализ русского текста.
- **NLTK** — токенизация предложений, контекстно-свободная грамматика `CFG`, синтаксический анализ `ChartParser` и деревья `Tree`.
- **Streamlit** — веб-интерфейс.
- **SVG** — графическое представление синтаксических деревьев.
- **unittest** — автоматическое тестирование.

## Установка и запуск (Windows PowerShell)

Откройте терминал в корневой папке проекта и выполните:

```powershell
python -m pip install -r requirements.txt
```

Запуск автоматических тестов:

```powershell
python -m unittest discover -s tests -v
```

Оценка качества на размеченном корпусе:

```powershell
python evaluate.py
```

Запуск веб-приложения:

```powershell
python -m streamlit run app.py
```

После запуска Streamlit откройте адрес, который будет показан в терминале (обычно `http://localhost:8501`).

## Тестирование и оценка качества

В каталоге `tests/` находятся модульные и интеграционные тесты пунктуационных правил, морфологической обработки, CFG-парсера и визуализатора деревьев.

В `data/benchmark.json` находится расширенный размеченный корпус из 216 предложений: 108 примеров с пунктуационными ошибками и 108 примеров с корректной пунктуацией. Дополнительный небольшой корпус хранится в `data/benchmark_v8_28.json`.

Скрипт `evaluate.py` запускает оценку на размеченных данных. Рассчитываются Precision, Recall, F1-score и Accuracy, в том числе показатели по группам правил и по частям корпуса. Подробный результат сохраняется в `reports/latest_benchmark_report.json`.

Метрики характеризуют только используемый вручную сформированный учебный корпус. Они не являются оценкой качества на случайной выборке реальных текстов и не доказывают универсальную точность анализатора.

## Ограничения

- SyntaxGuard — учебный эвристический анализатор, а не полноценный корректор русского языка.
- Пунктуационные правила покрывают ограниченный набор распространённых конструкций; сложные и неоднозначные контексты могут требовать ручной проверки.
- CFG является учебной и ограниченной: она покрывает типовые структуры, но не всю грамматику русского языка.
- Синтаксический разбор строится по последовательности морфологических категорий и не является полноценным анализом зависимостей или семантики.
- Для части предложений синтаксическое дерево может не построиться. Это не означает, что предложение неверно.
- Результаты метрик зависят от состава и разметки тестового корпуса; их нельзя автоматически переносить на все русские тексты.
