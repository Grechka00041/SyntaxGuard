# SyntaxGuard v9.1 — исправление ошибок тестового корпуса

SyntaxGuard — учебный пунктуационный анализатор русского языка на основе `pymorphy3` и ограниченного набора эвристических правил.

## Что исправлено в v9.1

- Обращения больше не должны определяться на месте подлежащего после начального деепричастного оборота: «Увидев друга, девушка улыбнулась».
- Добавлены повелительные формы «обрати» и «обратите» для распознавания обращения: «Коллеги, обратите внимание».
- Частицы «не» и «ни» перед деепричастием учитываются как часть начального оборота: «Не заметив ошибки, редактор отправил текст».
- Расширено распознавание постпозитивных причастий, которые морфологический анализатор может классифицировать как прилагательные (например, «дорога, ведущая к озеру»).
- `NPRO` отображается в `PRON`, чтобы местоимения-подлежащие учитывались при поиске второй грамматической основы.
- Противительный союз «а» проверяется и между частями с разными типами сказуемых: «День был пасмурным, а вечер солнечным».
- Уточняющая конструкция с уже расставленными двумя запятыми дополнительно проверяется по исходным позициям знаков, а разбор предложной группы стал терпимее к неоднозначным токенам.

## Состав проекта

Сохранены девять групп пунктуационных проверок, тестовый корпус `data/benchmark.json` (216 предложений), оценка метрик через `evaluate.py`, интеграционные и модульные тесты.

## Запуск (Windows PowerShell)

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python evaluate.py
python -m streamlit run app.py
```

## Ограничения

Это учебный эвристический анализатор, а не полноценный корректор русского языка. Правила охватывают распространённые учебные конструкции. Суффиксные и контекстные эвристики могут ошибаться на неоднозначных предложениях. Тестовый корпус сформирован вручную и не является случайной выборкой или независимой экспертной разметкой. Метрики описывают только используемый корпус и не доказывают качество на всех русских текстах.
