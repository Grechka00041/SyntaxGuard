# Оценка качества SyntaxGuard v9

## Состав корпуса

`data/benchmark.json` содержит 216 предложений: 108 примеров с пропущенными запятыми и 108 корректных контрольных примеров. Для каждой из девяти поддерживаемых групп правил предусмотрено по 12 положительных и 12 отрицательных примеров. Сходные по содержанию пары связаны полем `pair_id`; роль записи указана в `pair_role`. По шесть пар на каждую группу помещены в `development`, остальные шесть — в `holdout`, чтобы отдельно показывать результат на отложенной части корпуса. Это функциональное разделение, а не случайная выборка из внешнего источника.

Корпус составлен вручную для учебной проверки эвристик. Это не случайная выборка из реальных текстов и не корпус, независимо размеченный несколькими экспертами. Часть примеров специально отражает ограниченные шаблоны, которые поддерживает текущий код.

## Два уровня оценки

### Уровень предложения

Проверяется, обнаружил ли анализатор хотя бы одно замечание в предложении, где эталонная разметка указывает на пропуск запятой.

- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1 = 2 × Precision × Recall / (Precision + Recall)
- Accuracy = (TP + TN) / N

### Уровень группы правил

Множество `expected_rules` каждой записи сравнивается с множеством групп правил, фактически вернувших замечания. Так выявляются не только пропуски ошибки в целом, но и ложное срабатывание неправильного правила на предложении, где какая-либо пунктуационная проблема всё же есть.

Скрипт выводит Precision, Recall, F1 и Accuracy по каждой группе, макроусреднение по группам и долю точного совпадения наборов правил.

## Запуск

```powershell
python -m unittest discover -s tests -v
python evaluate.py
```

Полный результат сохраняется в `reports/latest_benchmark_report.json`.

## Как интерпретировать результаты

Показатели относятся только к данному учебному корпусу и покрываемым правилами шаблонам. Они не измеряют точность каждой отдельной позиции запятой, не доказывают качество на всех жанрах и текстах русского языка и не заменяют экспертную оценку. Для научно более строгого эксперимента нужны независимая разметка несколькими экспертами, согласование спорных случаев и отдельный отложенный корпус из реальных текстов.
